# Iman Shopp - Онлайн магазин сладостей

Современный интернет-магазин сладостей, напитков и кофе, созданный с использованием React + Vite и Redux.

## Особенности

- 🎂 Категории товаров: Торты и чизкейки, Напитки, Кофе и чай
- 🛒 Корзина покупок с Redux
- 📱 Полностью адаптивный дизайн
- 🍔 Бургер-меню для мобильных устройств
- 🔐 Страница входа/регистрации
- 📍 Интегрированная карта с адресом
- 🎨 Минималистичный и современный дизайн

## Технологии

- React 18
- Vite
- Redux Toolkit
- React Router DOM
- CSS3

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev-сервер:
```bash
npm run dev
```

3. Откройте браузер по адресу `http://localhost:5173`

## Сборка для продакшена

```bash
npm run build
```

## Структура проекта

```
src/
├── components/      # Переиспользуемые компоненты
│   ├── Header/     # Шапка сайта с навигацией
│   ├── Footer/     # Подвал сайта
│   └── ProductCard/ # Карточка товара
├── pages/          # Страницы приложения
│   ├── Home/       # Главная страница
│   ├── About/      # О нас
│   ├── Contacts/   # Контакты
│   ├── Team/       # Наша команда
│   ├── Login/      # Вход/Регистрация
│   ├── ProductDetail/ # Детальная страница товара
│   └── Cart/       # Корзина
├── store/          # Redux store
│   └── slices/     # Redux слайсы
├── data/           # Данные (товары)
└── App.jsx         # Главный компонент
```
